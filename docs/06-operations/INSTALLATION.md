# Installation

**Status:** Draft for future packaged releases. The application has not yet been implemented.

## End users
When a release is available: download only from the official project release page; verify publisher/signature where provided; run the installer and review OS prompts; launch Survey Copilot; configure an AI provider only if desired; review privacy/network disclosure before the first provider request.

Do not install unofficial repackaged builds or share provider API keys.

## Developers
Exact toolchain and commands will be added after the app scaffold is committed. Planned stack: Tauri 2, Rust, React, TypeScript. Follow repository README and lockfiles once available.

## Support
Report reproducible issues with OS version, app version, and redacted logs. Do not attach profile databases, API keys, or personal survey content.
