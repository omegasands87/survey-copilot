# Contributing

Thank you for your interest in Survey Copilot.

## Before contributing
- Read [README](README.md) and the [documentation index](docs/00-INDEX.md).
- Review the product boundary: this is a manual-review copilot, not an autonomous survey bot.
- Do not add CAPTCHA bypass, browser automation, autofill, auto-submit, deceptive screening, or fabricated personal data.
- For architectural changes, create or update an ADR.

## Development expectations
- Keep changes focused and typed.
- Add tests for behavior and regression cases.
- Update documentation when requirements, schema, security, or user-visible behavior changes.
- Never commit API keys, local databases, profile exports, or real survey responses.
- Use synthetic data in tests and examples.

## Pull requests
Include problem/intended behavior, scope/trade-offs, tests run/results, privacy/security impact, and documentation updates.

## Security reports
Do not publish exploit details or sensitive user data in a public issue. Establish a dedicated security contact before public release. Never share credentials or private data in a report.
